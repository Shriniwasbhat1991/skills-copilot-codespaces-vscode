# Windows Remote Desktop App (AnyDesk-Style)

If you want a Windows remote desktop app **like AnyDesk**, use:

## Recommended first choice
- **TeamViewer**
  - Very similar remote-support workflow to AnyDesk.
  - Good for personal help and business IT support.

## Also good options
- **RustDesk** (open-source, self-hostable)
- **Chrome Remote Desktop** (free and simple)
- **Microsoft Remote Desktop (RDP)** (best for internal Windows/VPN use)

## Simple answer
If you asked for “like AnyDesk,” start with **TeamViewer**.

## How to test
1. Install **TeamViewer** on both Windows PCs.
2. On the remote PC, open TeamViewer and copy the displayed ID and password.
3. On your local PC, enter the remote ID and click **Connect**.
4. Enter the password when prompted.
5. Verify you can:
   - Control mouse and keyboard
   - Transfer a small file
   - Reconnect after ending the first session
6. If TeamViewer is blocked by policy/network, repeat the same flow with **RustDesk** or **Chrome Remote Desktop**.
